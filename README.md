### AI UPI Transaction Analyzer
An LLM-backed analyzer that turns raw UPI statements into a queryable picture of personal spend, answering plain-language questions instead of returning another dashboard.

**Key Differentiator**
- Normalizes inconsistent UPI statement formats into a single schema before any model sees the data.
- Categorizes merchants and recurring payments, then grounds every answer in the parsed rows rather than free-generating numbers.
- Exposes the pipeline behind a FastAPI service so the same logic serves both batch analysis and interactive queries.

### Sentiment Analysis on ChatGPT Reviews
A transformer-based classification pipeline over user reviews that surfaces the themes behind each rating band instead of collapsing everything into a single score.

**Key Differentiator**
- Compares a fine-tuned transformer against classical baselines so the accuracy gain is measured, not assumed.
- Extracts recurring complaint and praise themes per rating band, which is where the actionable signal actually lives.
- Handles class imbalance explicitly rather than reporting inflated accuracy on a skewed dataset.

### AI Powered Skincare Recommendation System
A retrieval-grounded recommender that maps skin profile and ingredient constraints to products, with every suggestion traceable to a source in the ingredient corpus.

**Key Differentiator**
- Retrieves over a curated ingredient and formulation corpus, so recommendations cite evidence instead of hallucinating chemistry.
- Applies hard constraints — sensitivities, conflicting actives — as filters before ranking, not as afterthoughts in the prompt.
- Keeps the retrieval layer swappable, so the corpus can grow without touching the recommendation logic.
